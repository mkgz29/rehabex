# 💳 Payment Flow

1. User browses rehabilitation products
2. User adds products to cart
3. Checkout validates purchase data
4. Mercado Pago preference is created
5. User completes payment through Mercado Pago
6. Webhook receives payment notification
7. Order status is updated
8. Success page confirms the purchase
